# Sound licences

Every sound in `assets/sounds/` is listed here. All recorded sounds are real field recordings released under **Creative Commons 0 (CC0 1.0, public domain dedication)** on Freesound, so they may be used commercially with no attribution required. Credit is given here anyway.

Source audio was the Freesound high-quality preview (OGG Vorbis, 44.1/48 kHz stereo, about 190 to 330 kbps VBR) of each CC0 upload, because original-file downloads need a signed-in Freesound account.

## Processing (all files)

1. Decoded to 32-bit float, 44.1 kHz stereo, 20 Hz high-pass to remove DC and sub-rumble.
2. Picked the steadiest window (lowest 1 s loudness variance, no samples above -0.1 dBFS) of loop length + 4 s.
3. Seamless loop: the 4 s tail after the loop end is equal-power crossfaded into the first 4 s, so the last sample flows straight into the first one. The file is the loop; the app loops it gaplessly.
4. Static gain to about -20 LUFS integrated (measured over 3 back-to-back copies so the seam counts). For transient-heavy recordings, a look-ahead limiter (run over 3 copies, middle copy kept so the seam stays continuous) took off at most 8 dB of peaks; where that was not enough the file stays quieter rather than being squashed.
5. True peak at or below -1.0 dBTP after encoding (re-measured on the decoded AAC).
6. Encoded AAC-LC `.m4a`, 44.1 kHz stereo, 256 kbps target (320 kbps target where the encoder averaged under 256).
