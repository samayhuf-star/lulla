## IAP

RevenueCat (`react-native-purchases`) was removed. Purchases now use StoreKit 2 via `expo-iap` directly, with the store’s localized prices. There is no server.

Product IDs used (already in ASC, group “Lulla Premium”):

- `lulla_premium_yearly` — auto-renewing yearly
- `lulla_premium_monthly` — auto-renewing monthly

USA list prices from the earlier ASC check (not hard-coded in the app): $41.99 / year, $4.99 / month. The paywall shows whatever the store returns (`displayPrice`). If nothing loads, it shows neutral copy: “Plans unavailable right now. Please try again shortly.” / “Prices will appear here when the store is ready.”

Startup rules:

- Launch does **not** call `syncIOS`, `restorePurchases`, or `getAvailablePurchases`.
- Entitlement check uses `currentEntitlementIOS` plus `hasActiveSubscriptions` / `getActiveSubscriptions`, and the `Transaction.updates` listener.
- Sync / restore run only when the user taps Restore Purchases.
- The splash is hidden as soon as the UI mounts, before `initIAP`. `initConnection` is not on the first-render critical path.
- A source test in `scripts/iap-startup.test.ts` asserts the above.
