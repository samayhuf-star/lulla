# Lulla - Sleep Sounds

Expo (React Native) sleep-sounds app. 3 minutes free, then $1.99/month via RevenueCat.

- `App.tsx`, `src/` – app code
- `assets/sounds/` – 25 original synthesized loops
- `store/` – App Store / Play Store screenshots, feature graphic, listing copy, privacy policy
- `LAUNCH_GUIDE.md` – store, RevenueCat and EAS setup steps
- `extras/` – asset generator scripts
